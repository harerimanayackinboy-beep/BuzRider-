# BuzRider - Supabase

Migrations ziri muri `supabase/migrations/` (zikurikirana ku tariki).

Gukora types za TypeScript:
    npx supabase gen types typescript --project-id ixzwnvrndmarbfrrczbj > src/database.types.ts

Guhuza na project (rimwe gusa):
    npx supabase login
    npx supabase link --project-ref ixzwnvrndmarbfrrczbj
